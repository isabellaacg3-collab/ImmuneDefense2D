# ImmuneDefense2D

一款以人体免疫防御为主题的 2D 塔防游戏，使用 Unity 和 C# 开发。

玩家通过建造中性粒细胞防御塔、部署援军和管理免疫点数，阻止敌人沿道路抵达宿主，同时通过教程与知识卡了解相关免疫学概念。

当前版本：**0.1.0-alpha.1**  
运行平台：**Windows x86_64**  
作者：**isa.ss**

## 当前版本

本 Alpha 包含一个可完整游玩的 Level01，以及以下内容：

- 6 波敌人与可并行释放的 Group 小波次。
- 基础、快速、坚韧三种敌人。
- 中性粒细胞 Lv1 防御塔，包含持续触手链接与击杀吞噬表现。
- 援军部署、位置预览、自动索敌与拦截。
- 提前开波及成功开波后的援军冷却刷新。
- 波前资源补给、建塔与援军教学。
- 敌人首次出现提示、塔属性面板与知识卡。
- 手动暂停、教学暂停、胜利、失败及重新开始。
- 第一版地图、塔、敌人、援军、塔位美术与游戏 UI。

当前版本已由开发者完成 Unity Editor 和 Windows 独立程序的全流程测试。Alpha 阶段仍会继续收集问题并调整体验。

## 玩法

使用 ID 点建造防御塔，利用塔位与道路的相对位置组织防线。防御塔会自动寻找射程内的敌人并攻击。

援军解锁后，可以部署在道路附近，在有限持续时间内拦截并攻击敌人。

提前开波按钮会在允许的时间窗口内启用。提前开启下一波可能形成多波敌人同时进攻，也会刷新已解锁援军的冷却。

清除全部波次的有效敌人后获胜；宿主生命值耗尽则失败。

## 操作

| 操作 | 作用 |
| --- | --- |
| 鼠标左键点击空塔位 | 打开建造菜单 |
| 点击建造选项 | 消耗 ID 点建造防御塔 |
| 点击已建塔底部 | 打开塔操作面板 |
| 点击“详情” | 打开知识卡，阅读期间暂停 |
| 点击“部署援军” | 进入部署状态，显示位置预览 |
| 部署状态下左键点击有效位置 | 部署援军 |
| 部署状态下右键或再次点击部署按钮 | 取消部署 |
| 点击“提前下一波” | 在允许窗口内请求提前开波 |
| Esc | 打开／关闭手动暂停 |
| 右上角暂停按钮 | 打开手动暂停菜单 |
| 结算界面点击“重新开始” | 重开当前关卡 |
| Alt + F4 | 退出程序 |

首次游玩请跟随关卡教程完成建塔和援军部署。

## 运行 Windows 版本

1. 将完整发布压缩包解压到本地文件夹。
2. 双击 `ImmuneDefense2D.exe`。
3. 保留同目录的 `_Data` 文件夹、DLL 及其他运行依赖，不能只复制 exe。

发布包名称：

`ImmuneDefense2D-0.1.0-alpha.1-Windows-x64.zip`

运行发布包不需要安装 Unity Editor。

## 从源码运行

开发环境：

- Unity Editor **6000.3.19f1**
- C#
- Windows 开发环境

运行步骤：

1. 克隆或下载本仓库。
2. 在 Unity Hub 中添加项目根目录，使用对应版本的 Editor 打开。
3. 等待依赖解析与资源导入完成。
4. 打开 `Assets/Scenes/Level01.unity`。
5. 点击 Play，按开场教程开始游戏。

仓库保留 `Assets`、`Packages` 和 `ProjectSettings` 等项目文件；Unity 生成的 `Library`、`Temp` 及本地构建产物不纳入版本控制。

## 实现特点

- 使用 ScriptableObject 配置玩法数值、波次、关卡事件及视觉参数。
- 将波次拆分为多个 Group，分别配置出兵时间、数量和入口／出口。
- 自动开波与手动提前开波共用“请求 → 波前准备 → 实际出兵”的流程。
- 通过统一游戏状态和独立暂停请求，协调敌人、塔、援军及波次计时。
- 分离路径基准推进与横向位置计算，形成敌群交错行进的效果。
- 将攻击判定与触手、吞噬等视觉表现分开处理。

## 项目背景与开发方式

ImmuneDefense 最初通过 Roblox 原型验证了核心玩法，随后迁移至 Unity 2D。本仓库是 Unity 与 C# 的重建版本，并非对旧工程逐文件翻译。

项目同时作为 C#、Unity 和软件工程实践：核心机制通过编写、测试和迭代逐步建立；部分批量工程工作、视觉脚本及美术素材制作使用 AI 工具辅助完成。

## 题材说明

游戏中的拟态体为虚构敌人。触手链接、伤害数值和部分战斗效果属于玩法表达。

关卡教程主要解释游戏机制，知识卡介绍相关现实免疫学概念。
