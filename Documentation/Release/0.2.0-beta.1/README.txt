ImmuneDefense2D 0.2.0-beta.1
Windows x64 Beta

运行
1. 完整解压 ZIP 到本地文件夹。
2. 双击 ImmuneDefense2D.exe。请保留同目录的 _Data 文件夹、DLL 和其他运行依赖。
3. 在人体地图上点击骨髓入口，打开关卡详情，再点击「进入关卡」。

操作
- 鼠标左键点击空塔位建塔，点击已有防御塔查看详情和当前可用操作。
- 援军和抗体风暴解锁后，可选择技能并点击道路上的有效位置。
- Esc 或暂停按钮打开暂停菜单。「回到选关」会放弃当前局。
- 胜负结算后可重试或回到选关。第一关通关后开放第二关，重启后保留通关记录。
- Alt+F4 退出程序。
