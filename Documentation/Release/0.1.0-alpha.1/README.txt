ImmuneDefense2D 0.1.0-alpha.1
Windows x86_64 Alpha

运行：完整解压本文件夹，双击 ImmuneDefense2D.exe。请保留同目录所有依赖及 _Data 文件夹。
操作：鼠标左键点击塔位建造；点击已有细胞查看信息，按教程开始战斗。
援军解锁后点击“部署援军”，将鼠标移到道路附近并左键部署；右键或再次点击部署按钮取消。
点击“提前下一波”可在允许的窗口内提前开波。
Esc 暂停/继续，也可使用右上角暂停按钮。
在暂停或结算界面点击“重新开始”重开当前关卡。Alt+F4退出。

已知限制：单关Alpha；升级与拆除尚未开放；初版美术与数值仍会迭代。
